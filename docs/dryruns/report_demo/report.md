## 7. How to verify this report

Run: python3 tools/verify_report.py --report-dir <this directory> --pin-fingerprint <the Visionblox release key fingerprint from the Technical Delivery Sheet>. The verifier is standalone: standard library plus `cryptography`, no network, no credentials, and no import from the Relian source tree. It prints its own SHA-256 so you can confirm it is the tool that was shipped to you. Exit 0 means all four layers passed. Exit 3 means the report is VALID AND UNATTESTED — the instance layer passed and no Visionblox countersignature is present. Any other non-zero exit means a named layer failed.

| Layer | What it checks |
| --- | --- |
| FILES | every path recorded in the manifest exists and hashes to its recorded SHA-256 |
| MANIFEST | the manifest hash, recomputed from the manifest minus its signature block, equals the value the signature was taken over |
| INSTANCE | the Ed25519 instance signature verifies over that manifest hash, under the fingerprint the manifest records |
| COUNTERSIGNATURE | the detached Visionblox countersignature verifies over the same manifest hash, under the release-key fingerprint YOU pin on the command line. The pin is required: an unpinned check would accept a report re-signed under any key at all. |
